# R J Hill Homes Electrical Tool

This is a clean Vite + React starter bundle.

## Upload structure
Upload these files exactly as they are to a brand new GitHub repository:

- index.html
- package.json
- vite.config.js
- .gitignore
- README.md
- src/main.jsx
- src/App.jsx
- src/styles.css

## Vercel settings
- Framework Preset: Vite
- Root Directory: leave empty
- Build Command: npm run build
- Output Directory: dist
